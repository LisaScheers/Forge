# Upstream and adaptation

This skill set adapts `cursor/plugins` pstack at commit `60c641e4fad674784b30abcf9f8915dea39df38d`.

Upstream project: https://github.com/cursor/plugins/tree/main/pstack

The upstream code is MIT licensed. This adaptation preserves the engineering intent while replacing Cursor paths, slash commands, custom agent types, model configuration, and cloud-agent assumptions with Codex skills and collaboration tools. Forge's `pstack-incompatibilities.html` records behavior that was changed or intentionally omitted.
