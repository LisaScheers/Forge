# Linden Scripting Language (LSL)

## limitations

- LSL is a simple scripting language with limited functionality compared to full programming languages.
- The lsl runtime has a memory limit of 16KB, so scripts must be small and efficient.
- LSL has a limited set of built-in functions and data types, so some tasks may not be possible or may require creative workarounds.

## best practices

- Use descriptive names for variables and functions to improve code readability.
- Comment your code to explain the purpose of functions and complex logic.
- Avoid using global variables when possible, as they can lead to unexpected behavior and make code harder to maintain. they also use up memory quickly, so use them sparingly.
- use built-in functions and data types whenever possible, as they are optimized for performance and memory usage.
- when a script gets too large, consider splitting it into multiple scripts or using external data sources to reduce memory usage.
